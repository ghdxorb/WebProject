<form> 태그를 이용해서 보내고 받으면되는 데  json 을 쓰는 이유?
전통적인 <form> 태그를 쓰면 훨씬 간단해 보이는데, 요즘 개발자들이 굳이 자바스크립트(fetch)를 쓰고 JSON이나 FormData를 이용해 데이터를 보내는 데는 명확한 이유가 있습니다.
가장 큰 차이는 "페이지가 새로고침(깜빡) 되느냐, 안 되느냐"의 차이입니다.

1. 옛날 방식: 순수 <form> 태그 전송<form action="/DataSaveServlet" method="POST">를 쓰고 등록 버튼을 누르면 다음과 같이 작동합니다.
동작: 브라우저가 화면 전체를 백지 상태로 만들고, 서버로 데이터를 보낸 뒤, 서버가 새로 그려준 화면(JSP 등)을 다시 받아옵니다.
단점 (화면 깜빡임):글 하나 등록할 때마다 화면 전체가 '투둑'하고 새로고침됩니다.
만약 사용자가 음악을 듣고 있었다면 음악이 끊기고, 작성 중이던 다른 폼이 있었다면 날아가 버립니다.
서버는 데이터 저장만 하면 되는데, 굳이 다음 화면(HTML 전체 코드)까지 새로 만들어서 브라우저에 던져줘야 하므로 서버와 네트워크에 부담이 커집니다.

2. 요즘 방식: 자바스크립트(fetch) + JSON 전송질문하신 코드처럼 자바스크립트의 fetch를 사용해 JSON으로 보내면 다음과 같이 작동합니다.
동작 (비동기 통신): 사용자가 보는 화면은 그대로 가만히 멈춰있는 상태에서, 뒷구멍(배경)으로 데이터만 쏙 서버로 보냅니다.
장점 (부드러운 사용자 경험):화면 깜빡임이 전혀 없습니다.
서버는 화면을 새로 그릴 필요 없이, 딱 "성공했다/실패했다"라는 짧은 글자(JSON)만 대답해주면 됩니다.
브라우저(자바스크립트)는 서버의 짧은 대답을 듣고 alert()을 띄우거나, 내 마음대로 부드럽게 다른 페이지(location.href)로 이동시킬 수 있습니다.

쉽게 비유하자면
<form> 태그 방식: 은행 업무를 보려면 하던 일을 다 멈추고, 직접 은행 창구(서버)까지 걸어가서 서류를 내고 새 서류를 받아오는 것과 같습니다. (화면 이동/전체 새로고침)
fetch + JSON 방식: 스마트폰 뱅킹 앱을 쓰는 것과 같습니다. 
나는 침대에 가만히 누워있고(화면 유지), 앱이 알아서 뒷단으로 데이터만 송금한 뒤 결과만 화면에 띄워줍니다. (데이터만 교환)
결론단순히 옛날 방식의 웹사이트를 만들거나, 화면이 무조건 깜빡이며 넘어가도 상관없다면 <form> 태그만 쓰셔도 아무 문제 없습니다! 
실제 파일 업로드도 <form enctype="multipart/form-data">로 가능합니다.
하지만 모바일 앱처럼 부드럽고 매끄러운 웹사이트를 만들고 싶다면, 화면을 유지한 채 데이터만 주고받는 자바스크립트(fetch)와 JSON 방식을 사용해야 합니다.


과거에는 비동기 통신(Ajax)을 하려면 브라우저마다 코드가 다르고 작성법이 복잡해서, 
이를 쉽게 도와주는 jQuery(질문하신 jquery.min.js) 라이브러리를 필수로 사용했습니다.하지만 지금은 jQuery 없이도 비동기 통신이 가능한 이유와 변화

1. 이미 fetch를 쓰고 계시기 때문입니다
작성하셨던 fetch('/free/write', ...) 코드가 바로 jQuery 같은 외부 라이브러리 도움 없이, 
브라우저에 기본으로 내장된 최신 비동기 기술입니다. 크롬, 사파리, 엣지 등 요즘 모든 브라우저가 fetch를 기본 지원하므로 jQuery를 불러올 필요가 없습니다.

2. 과거(jQuery)와 현재(Fetch)의 코드 비교
과거에 jQuery로 비동기 통신을 할 때는 아래처럼 $.ajax를 썼습니다.과거 (jQuery 방식 - 라이브러리 로드 필요)

// 이 코드를 쓰려면 위 jquery.min.js가 반드시 필요했습니다.
$.ajax({
    url: '/api/notice',
    type: 'POST',
    contentType: 'application/json',
    data: JSON.stringify(data),
    success: function(response) {
        alert("성공");
    }
});


현재 (순수 자바스크립트 Fetch 방식 - 라이브러리 필요 없음)
// 아무것도 설치 안 해도 브라우저가 바로 이해합니다.
fetch('/api/notice', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
})
.then(response => response.json());

현재 만들고 계신 코드에서 $.ajax, $("#id") 같은 jQuery 문법을 쓰지 않고 
오직 fetch와 순수 자바스크립트(document.getElementById 등)만 쓰고 계신다면, 위 <script> 태그는 과감히 지우셔도 똑같이 잘 작동합니다. 
용량만 차지하는 무거운 라이브러리를 뺄 수 있어서 웹사이트가 더 가벼워집니다
